# Saturday 21 November 2026: 46 date-checked stories, 7 regions — COP31 overtime, El Chapo captured, Peru quake 6.7

One newspaper front page summing up Saturday 21 November 2026 in a single
1024×1024 image: 3 leads, 10 picture stories and 33 briefs — 46 stories
across 7 regions (Americas 10, Europe 14, Middle East 7, Asia-Pacific 8,
Africa 5, Oceania 1, Global 1). Every story is dated to Saturday 21
November 2026, and the page says so itself: a red-bordered **DATE CHECK**
box lists the Friday and Thursday news that was deliberately left out, so
nothing from another day sneaks in as Saturday's news.

Three things no other entry on the board has: a **WHAT TO WATCH — SUNDAY
22 NOV** strip (Nepal's PM in India, the Las Vegas Grand Prix, the COP31
final text), a **SATURDAY MARKETS** mini-box with Saturday-only prices
(Bitcoin $58,983, Ether $1,625 — never Friday's close), and a **QUOTE OF
THE DAY** pull-quote ("Good deal or no deal." — Wopke Hoekstra, EU climate
chief). A numbered world map pins the 13 lead and picture stories, a UTC
timeline runs the day from the 00:09 Peru quake to England's 37–12 rugby
win, and a numbers strip leads with the day's six sharpest figures.

All drawings are original flat SVG illustrations drawn in code — no AI
images, no external files, no network at render time.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `out/entry.png`. The program copies the rendered `entry.png`
(1024×1024, 383,065 bytes) to the output directory, verifying first that
it is a valid PNG of exactly 1024×1024 and under the 1 MiB gate limit.

To re-render from source, open `frontpage.html` in headless Chromium at
1024×1024 and screenshot it — two renders produce byte-identical PNGs.
